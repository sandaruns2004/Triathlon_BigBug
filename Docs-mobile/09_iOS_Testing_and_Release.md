## Implemented build command

On the configured Mac with the authorized profile/keychain:

```bash
flutter build ipa --release --flavor production \
  --dart-define-from-file=config/ios-production.json \
  --export-options-plist=ios/ExportOptions.local.plist
```

The workflow creates the ignored configuration/export files from protected inputs; do not commit signing files. The resulting App Store IPA is for App Store Connect/TestFlight distribution, not unrestricted direct installation on arbitrary iPhones.
