WAYPOINT FLOW — GOOGLE STITCH WEB UI PROMPTS

Use each prompt separately in Google Stitch to create high-fidelity responsive desktop web UI, designed first at 1440 px wide. Waypoint Flow is a connected delivery-planning system for a Sri Lankan retail group with three brands: Waypoint Fresh, Waypoint Style, and Waypoint Tech. It connects ordering → planning → loading → delivery → receipt. The visual system must be clean and operational: white surfaces, deep forest green #146B45, primary action green #1F8A5B, pale green #EAF6EF, success #168050, ink #17221D, muted text #63716A, border #DCE5DF, and canvas #F6F8F7. Use amber for attention/at-risk work, red only for blocked/failed work, and blue-grey for informational states. Never use colour as the only status signal. Use Inter or similar modern sans-serif: page titles 28–32 px, section headings 18–20 px, body 14–16 px, tabular figures for times and capacity. Use 10 px card/control radius, 14 px large-panel radius, subtle borders, sparse soft shadows, readable data tables, and generous whitespace. Avoid generic dashboards, heavy gradients, and decorative illustrations in time-critical screens.
