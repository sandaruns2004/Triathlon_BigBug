# Mobile — Store Manager Home

## Purpose

Give a busy outlet manager immediate confidence about incoming deliveries and a fast path to ordering.

## Layout

- **Header:** outlet name, current day/date, notification bell.
- **Hero delivery card:** today’s most relevant order: status, arrival window, key change, and `Track delivery`. Deferred orders use a distinct card with revised date and reason summary.
- **Quick actions:** `New order`, `Order history`, `Confirm receipt`, `Report issue`.
- **Recent activity:** compact timeline of submission, plan confirmation, route departure, delivery, and messages.
- **Attention section:** only actionable notices (cut-off today, deferred order, receipt awaiting confirmation, response on issue).

## Behaviour

- If no delivery is due, the hero becomes `Plan your next delivery` with the next eligible date/cut-off.
- A notification deep-links to the specific order and preserves read/unread state.
- The home screen avoids fleet details and operational jargon; it translates status into what the outlet needs to know and do.
