# Asset attribution

Brand mark and selected mobile PNG illustrations were copied unchanged from Docs-ui/items/generated-assets. Original generated/hand-authored provenance is in that directory's README. The illustrations are project drafts, not photographed operational evidence.

Inter variable font: https://github.com/google/fonts/tree/main/ofl/inter ; the bundled OFL.txt contains its SIL Open Font License.

Lucide outline icon font is supplied by the locked lucide_icons_flutter package. License/provenance: https://pub.dev/packages/lucide_icons_flutter and https://lucide.dev/license . Native widgets replace React-only components while preserving the project's outline icon style.

All needed UI assets/fonts ship with the app; runtime downloads are not needed for cold-start rendering.
