# 00 · Event Overview — Tech-Triathlon 2026

## About Tech-Triathlon

Tech-Triathlon 2026 is a 15-day multi-discipline hackathon/challenge organized by **RootCode** for undergraduate teams. It spans three parallel challenges (Designathon, Hackathon, Datathon) released together in a single booklet.
